이 방침은 Windows용 개인 데스크톱 캘린더인 Daylight Calendar(이하 “앱”)와 앱 소개 웹사이트에서 정보를 처리하는 방식을 설명합니다.

1. Google 연결 및 요청 권한

Google Calendar 연결은 선택 사항입니다. 사용자가 앱에서 Google OAuth 절차를 진행하고 직접 접근 권한을 승인하면 앱이 승인 범위 내에서 Google Calendar에 접근합니다.

앱이 요청하는 권한은 다음과 같습니다.

https://www.googleapis.com/auth/calendar.calendarlist.readonly

사용자의 Google Calendar 캘린더 목록을 읽는 데 사용합니다.

https://www.googleapis.com/auth/calendar.events

Google Calendar 일정을 조회하고, 사용자가 요청한 일정을 추가·수정·삭제하는 데 사용합니다.

2. 처리하는 정보와 이용 목적

앱은 사용자가 입력한 로컬 일정과 Google 연결 시 승인된 범위의 캘린더 목록 및 일정 정보를 처리합니다. 일정 정보에는 제목, 날짜·시간, 장소, 설명 등 일정 관리에 필요한 정보가 포함됩니다.

이 정보는 달력 표시와 사용자가 요청한 일정 조회·추가·수정·삭제에 사용됩니다. Google 인증 정보는 Google Calendar 연결과 필요한 API 요청을 수행하는 데 사용됩니다.

3. PC 저장 및 보호 방식

  • 로컬 일정과 최근 조회한 Google 일정 캐시는 사용자 PC에 저장됩니다.
  • 인증 정보는 Electron의 safeStorage를 통해 Windows에서 암호화하여 저장합니다.
  • 일정 내용 자체는 암호화하지 않습니다. 인증 정보의 암호화와 일정 내용의 저장 방식은 서로 다릅니다.
  • 앱 운영자가 별도로 운영하는 서버로 일정 데이터를 수집하거나 보관하지 않습니다.

PC에 저장된 정보의 보호를 위해 Windows 사용자 계정과 기기 접근 권한을 안전하게 관리해 주세요.

4. 전송 및 제3자 제공

Google 인증 및 Google Calendar API 통신에는 인증과 일정 관리에 필요한 정보가 Google로 전송됩니다. 예를 들어 사용자가 Google 일정을 추가·수정·삭제하면 해당 요청 수행에 필요한 일정 정보가 Google로 전송됩니다.

앱은 Google 사용자 데이터를 판매하지 않으며, 광고 또는 AI 모델 학습에 사용하지 않습니다.

Google 서비스에서 이루어지는 정보 처리는 Google 개인정보처리방침도 함께 참고해 주세요.

5. 연결 해제와 삭제

  • 앱의 Google 연결 해제 기능은 Google 접근 토큰의 권한 취소를 요청합니다.
  • 권한 취소 요청이 성공하면 이 기기의 인증 정보와 Google 일정 캐시를 삭제합니다. 로컬 일정은 유지합니다.
  • 연결 해제가 실패하면 삭제가 완료된 것으로 간주하지 마세요. 연결 상태를 확인하고 다시 시도할 수 있습니다.
  • Google 계정의 연결 설정에서도 앱의 접근 권한을 취소할 수 있습니다. Google 계정에서의 권한 취소와 앱 내에서의 이 기기 데이터 삭제는 구분됩니다.
  • 앱 연결 해제는 Google 계정에 저장된 일정 자체를 삭제하지 않습니다.
  • 로컬 일정은 앱의 일정 삭제 기능으로 삭제할 수 있습니다. Google 계정의 일정 삭제는 연결 해제와 별개의 일정 관리 작업입니다.

6. 웹사이트와 GitHub Pages

이 웹사이트는 앱 소개와 개인정보처리방침 안내를 위한 정적 페이지입니다. 웹사이트에서는 Google 로그인, 일정 조회 또는 일정 관리를 직접 수행하지 않습니다.

홈페이지에는 분석 도구, 광고 추적, 방문자 추적 기능 또는 불필요한 외부 스크립트를 설치하지 않습니다.

다만 이 웹사이트는 GitHub Pages에서 호스팅되므로, 웹사이트 제공 및 보안 운영 과정에서 GitHub가 IP 주소 등 접속 정보를 처리할 수 있습니다. 이는 앱 운영자의 일정 데이터 수집과는 별개입니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

7. 문의 및 방침 변경

앱 및 개인정보 처리 관련 문의는 홈페이지 운영 저장소의 GitHub Issues로 접수합니다. 문의 작성에 GitHub 로그인이 필요할 수 있습니다.

Issues는 공개 게시판입니다. 실제 일정 내용, 계정 정보, OAuth 설정 파일, 비밀 키, 인증 토큰 등 개인정보나 민감한 정보를 게시하지 마세요.

앱의 정보 처리 방식이 변경되면 이 페이지에 변경 내용을 반영하고 시행일 또는 최종 수정일을 갱신합니다.
